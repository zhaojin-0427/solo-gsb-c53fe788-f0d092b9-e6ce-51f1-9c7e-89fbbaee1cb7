# 航标灯质可辨性预检台

供航标灯质设计人员使用的**本地 Web 预检台**：保存若干盏灯的循环亮灭串，设定观测窗口上限与允许误判位数后，对每两盏灯**完整穷举各自独立的起始相位**，求出保证可辨所需的最短观测窗口；若窗口上限内仍无法区分，则给出仍混淆的灯对、距离最近的相位组合及逐位差异。

- 后端：Python 3.11 + FastAPI + SQLite（NumPy 做全量相位的向量化穷举，**不抽样、不跳过任何相位**）
- 前端：原生 JavaScript（无框架、无构建步骤）
- 一键启动：Docker Compose

---

## 一、启动方式（Docker Compose，推荐）

要求已安装 Docker 与 Docker Compose 插件。在本目录（含 `docker-compose.yml`）执行：

```bash
docker compose up -d --build
```

首次构建会拉取 `python:3.11-slim` 并安装依赖，之后启动只需：

```bash
docker compose up -d
```

停止服务：

```bash
docker compose down
```

## 二、访问方式

启动后用浏览器打开：

> **http://localhost:8000**

- 「编辑分析」页：维护 2～20 盏灯及参数 → 点击「保存并穷举分析」→ 右侧查看结论、波形与逐位见证；编辑内容以草稿自动保存。
- 「历史记录」页：查看每次分析保存下来的**不可变快照**（分析结果保存时即固定当时灯串与 W/k，后续编辑不会改变既有结果）。

数据持久化在 Docker 卷 `beacon-data`（容器内 `/srv/backend/data/beacon.db` 的 SQLite 文件），重建容器不会丢失。端口可在 `docker-compose.yml` 的 `ports` 中修改（如 `18000:8000`）。

## 四、输入规则

| 项目 | 规则 |
| --- | --- |
| 灯数量 | 2～20 盏 |
| 每盏灯的循环串 | 长度 2～80 位的 `0/1` 串，且必须**同时含 0 和 1**；`1`=亮、`0`=灭，每位对应 **0.1 秒**，整串循环播放 |
| W | 观测窗口上限，1～400（位） |
| k | 每段观测最多允许误判位数，0～3 |

## 五、判定与穷举算法

1. 对任意两盏灯 A、B（周期分别为 `la`、`lb`），取 A 的起始相位 `p = 0..la-1`、B 的起始相位 `q = 0..lb-1`，**两组相位各自独立，共 `la × lb` 种组合全部枚举**（前端展示每组灯实际枚举的组合数）。
2. 对每个相位组合，逐位比较两盏灯循环展开后的前 n 位，得到汉明距离 d(p,q,n)；再对全部相位取最小：

   ```
   d_min(n) = min_{p,q} d(p, q, n)
   ```
3. 判据：**d_min(n) > 2k** 时，即使每段观测最多出现 k 位误判，两盏灯也不可能被混淆（码字最近邻界），即该对在 n 位观测下可辨。
4. 对每一对灯取 1～W 内首个满足条件的长度 n（因 d_min(n) 随 n 非递减，该 n 即该对的最短可辨长度）；**所有灯对都满足时**，取各对 n 的最大值为整个方案的最短可辨窗口 **N\***，并展示在 1～W 范围内。
5. 若至少一对在 W 位下仍有 d_min(W) ≤ 2k，则 W 位内**无解**：页面列出这些仍混淆的灯对、各自在 W 位下距离最近（最易混淆）的相位组合，并以红色列逐位标出差异位（位置从 1 起计数）。

穷举通过 NumPy 广播一次性构造每对灯全部 `la × lb × W` 的逐位比较张量，逐对顺序处理、用完即释放，数学上覆盖全部相位与全部位，没有随机抽样、启发式剪枝或相位跳过。最坏输入（20 盏 80 位、W=400，合计约 121.6 万个相位组合）在普通机器上约 7 秒完成，峰值内存约 50 MB。

### 页面展示内容

- 结论横幅：最短窗口 N\*（含秒数）或「W 位内无解」及混淆对数；
- 各灯循环波形（前 W 位）；
- 每对灯的最小距离曲线 d_min(n)（含 2k 阈值线与首次可辨点）、枚举相位组合总数；
- 逐位见证：距离最近的相位 p/q（含换算秒数）、两串对齐波形（红列 = 差异位）、差异位序号列表与原始位串。

## 六、不可变结果说明

点击「保存并穷举分析」后，系统把**当时的灯串、名称、W、k 与完整分析结果**作为一条快照写入 SQLite 的 `analyses` 表并返回编号。历史记录只能查看、追加，不会被之后的编辑改写；编辑器草稿与分析快照相互独立。
